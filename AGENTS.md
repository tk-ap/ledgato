# Agent Instructions

## Product role

Ledgato is the authorization control plane for AI agents. It maps effective authority, verifies boundaries, evaluates policy, requires approval, blocks prohibited actions, detects drift, and produces evidence.

### Boundaries

- Ledgato governs what agents may do.
- ALVIRA Bridge governs what context agents may know.
- Agent OS / Workflow Studio owns workforce composition and routing.
- Ailhat owns portfolio priority and outcome measurement.
- Agentic harnesses execute authorized work.
- Do not turn Ledgato into a portfolio manager, context store, workforce planner, or harness-specific executor.

## Shared Agent OS and ecosystem awareness

Before material work, read `tk-ap/agent-os` `BOOTSTRAP.md`, `ecosystem/ECOSYSTEM.md`, `ecosystem/products.yaml`, `products/ledgato.md`, and this repository's `.agent-os/` manifests.

Consume capability manifests and authority requests through shared contracts. Return explicit allow, deny, or approval-required decisions with verifiable evidence.

At completion report Product result, Ecosystem implications, Cross-product opportunities, and Boundary check. Cross-product promotion must follow Agent OS `ecosystem/cross-market-policy.md`.
